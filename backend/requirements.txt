# Backend dependencies. Python 3.11.
#
# ---------------------------------------------------------------------------
# INSTALL IN THIS ORDER
# ---------------------------------------------------------------------------
#     python backend/install_torch.py        <- FIRST. GPU build of torch.
#     pip install -r backend/requirements.txt
#     python backend/fetch_wilor.py          <- hand model, ~2.5 GB, once
#
# Running pip before install_torch.py gets you a CPU-only torch, which is
# 20-50x slower. The backend refuses to start in that state and tells you to
# run install_torch.py, so the mistake costs a wasted download, not a bad
# event. Check at any time with:
#
#     python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
# A version with no +cuXXX suffix, or False, means the CPU build.
#
# ---------------------------------------------------------------------------
# Why torch needs its own step
# ---------------------------------------------------------------------------
# torch and torchvision are pinned below, but WITHOUT an index. That is a
# version pin only: PEP 440 ignores the local version segment, so 2.6.0+cu124
# and 2.6.0+cu118 both satisfy `torch==2.6.0`. What that buys:
#
#   * A correct CUDA install is never clobbered - pip sees the pin already
#     satisfied by the +cuXXX build and leaves it alone.
#   * One pin covers every machine, even though they need different wheels.
#   * Without it, pip resolved torch transitively to 2.14.0 / torchvision
#     0.29.0 - versions nothing here has been tested against.
#
# What a pin cannot do is choose the CUDA wheel, because the right one depends
# on the driver. A cuXXX wheel needs a driver built against at least that CUDA
# version, and `nvidia-smi`'s "CUDA Version" field is that maximum - a ceiling,
# not a target. Two machines, both verified working as of 2026-09-01:
#
#     driver 537.70 (max CUDA 12.2)  ->  cu118
#     driver 560.70 (max CUDA 12.6)  ->  cu124
#
# install_torch.py reads that and picks the wheel. By hand, if you prefer:
#
#     pip install torch==2.6.0 torchvision==0.21.0 #         --index-url https://download.pytorch.org/whl/cu118 #         --extra-index-url https://pypi.org/simple
#
# (swap cu118 for what your driver supports; the second index is required, or
# torch's own dependencies cannot be resolved on a clean machine.)
#
# Putting an index in THIS file would not work: a CUDA index hardcodes one
# choice and breaks the other machine, and the CPU index guarantees a wasted
# 2.5 GB re-download on every correct setup.
#
# ---------------------------------------------------------------------------
# About the pins
# ---------------------------------------------------------------------------
# These are the versions this backend actually runs, not aspirational
# minimums. The file had drifted badly once - it pinned numpy==1.24.4 while
# the working venv had 2.4.6, a major version and an ABI break apart - so a
# clean install built an environment meaningfully different from the tested
# one.

# ---------------------------------------------------------------------------
# Optional
# ---------------------------------------------------------------------------
# Second QR decoder. main.py prefers it when importable and falls back to
# OpenCV's built-in detector otherwise, so omitting it is safe.
#
# It is listed because the two decoders fail on different inputs and having
# both costs ~800 KB. It is NOT listed because it is better: the claim that
# pyzbar handles small, angled and blurred codes "noticeably better" came with
# the original code and had never been measured. Measured here on synthetic
# codes, it matched OpenCV on tilt up to 0.32 and LOST on a 44px blurred code
# OpenCV still read. Real camera frames carry perspective, uneven lighting and
# JPEG artefacts those tests do not, so treat both as unproven and judge from
# live QR mode.
#
# Windows note: the wheel bundles the zbar DLLs, but loading them needs the
# Visual C++ 2013 redistributable - the usual cause of an ImportError after a
# successful install.
pyzbar==0.1.9
