# sign-consistent on a held pose and its sign convention was inverted, versus

#

# (non-commercial research, registration) and its loader needs chumpy, which
# cannot install on Python 3.11. MANO only converts parameters into a mesh,
# which this pipeline never uses, so the layer is stubbed out.
#
